Deploy the Complete Package

  1. Extract Bakerss_Site_Technical_Upgrade.zip. Open the bakerss-site-main folder.
  2. Replace the contents of your existing site repository with the folder’s contents, preserving your repository connection. Upload folders and files together; the root vercel.json, shared assets, canonical article folders and sitemap are part of the fix.
  3. Run your normal deployment. This package retains the static HTML structure and existing hosting configuration. It has not been published.
  4. Check Home, Get Quote, Commercial Maintenance, Garden City Neighborhoods, Surfside Landing and Conway Neighborhoods on desktop and mobile.
  5. Confirm the FormSubmit destination is activated. Send a real test request after deployment, confirm receipt at info@bakerss.com, and confirm that the request appears once in analytics.
  6. Submit or refresh https://www.bakerss.com/sitemap.xml in Search Console and inspect your priority service URLs.

The 48 restored article routes use content already in the archive. This batch does not create 48 new articles. It makes the declared canonical destinations accessible and routes the previous file locations to them.
